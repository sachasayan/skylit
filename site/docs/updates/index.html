Guides/Frame care

Update Skylit

Download and install verified releases while keeping your frame’s settings.

Check and install

  1. Open Settings → Frame → Software updates and choose Check now. A published release with a newer version code is required.
  2. Read the release information and choose Download update. Wait for download and verification to finish.
  3. If prompted, allow Skylit to install packages in its Android app-specific settings. This is separate from USB or wireless debugging.
  4. Choose Install update and complete any Android confirmation. The old app closes during installation; reopen Skylit if it does not return automatically.

Do not uninstall or clear data to update. Only a correctly signed in-place upgrade preserves your private settings and cached media.

Choose an update policy

Manual checks only when you ask. Notify me checks for releases. Download also downloads a verified APK. Install when idle adds installation during your chosen window after five minutes without touch.

Downloads and installation are opt-in. The installation window follows your configured city timezone. Manual photo viewing, external services and Settings defer an idle installation; Android may still require confirmation.

What is verified

Skylit verifies the APK hash, package, newer version code and matching signing certificate before installation. It only checks this project’s published GitHub releases. A push to the repository, draft release or prerelease is not an app update.

If a check or download fails, the installed app continues working. Check connectivity and free storage, then retry. A signature mismatch should be investigated, not bypassed by uninstalling.
