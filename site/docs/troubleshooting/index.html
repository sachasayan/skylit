Guides/Frame care

When something isn’t working

Check connectivity, cached content and recovery options before changing your setup.

Check the basics

Confirm Wi-Fi is connected and the Android clock is correct. Open Settings → Help & maintenance for service status and retries. Settings → Frame has Android recovery shortcuts.

A last-checked time is more useful than a saved connection field. For photos, verify an imported picture; for calendars, verify an owner-made event change.

Photos, calendars and websites

Photos: check the selected source, mail status, retention window, exclusions and review queue. An email failure keeps previously saved pictures. Check the dedicated account’s app password on the frame; never share it with support.

Calendar: check source visibility, inviter rules, the selected date and last refresh. Overview shows today’s upcoming events regardless of the month you are browsing.

Home and YouTube: sign in on the frame if required. A website may impose WebView compatibility limits. An opened shortcut does not guarantee sign-in, playback or a working home control.

Dashboard and updates

Select a widget before using its corner handles. You can touch around the small corner mark; the target is larger than it looks. Release to save. If a placement is invalid, make room or use Reset to default.

If an update fails, keep the installed app, check the error and retry from Software updates. Do not erase data, weaken authentication or disable system apps as a troubleshooting step.

Report a problem

Open a GitHub issue with the Skylit version, frame model, Android version and the steps that reproduce the problem. Include only sanitized screenshots. Keep credentials, account names, household content and device identifiers out of the report.
