Guides/Getting started

Install Skylit

Check your frame, install the signed app and keep a way back to its original launcher.

Before you start

Skylit is an Android dashboard for landscape photo frames. The tested device is a Skylight 150-FRM / D156 running Android 12 with Chromium WebView 95 at 1920 × 1080. Other models are not certified.

Your device must already permit Android app installation. Skylit does not unlock, root or flash a frame. Keep the original launcher installed, and record its HOME component before changing your default home app.

Install the signed APK

  1. Download the latest normal Skylit APK from the GitHub release linked in the header.
  2. For an existing Skylit installation, install the update in place. Do not uninstall or clear app data: that removes private settings and cached pictures.
  3. For an initial ADB installation, select the exact authorized USB device and verify its model and Android version. Install with adb -s YOUR_USB_SERIAL install -r skylit-VERSION.apk, then launch com.wesbos.homehq/.MainActivity.
  4. Open Skylit and follow the first-run guide. Keep Wi-Fi connected and the device clock correct.

Use the same signing identity for upgrades. A signature mismatch is not a reason to uninstall your working app. See the repository’s build and wireless guides for developer installation details.

Keep a recovery path

Settings → Frame includes shortcuts to Android settings. Settings also offers Open original Skylight app on the tested frame; a two-finger hold opens that app too.

Making Skylit the default launcher is optional. Record your original HOME selection so you can restore it. Do not use another frame model’s firmware or recovery image.
