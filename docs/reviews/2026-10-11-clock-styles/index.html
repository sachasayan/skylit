Choose a clock

Every style uses the selected city’s timezone and daylight saving rules. Classic, Stacked and Digital follow the 12/24-hour setting. The analog dial uses twelve hours; its accessible time follows the same preference.

A live sample before saving

Select Clock & date in the layout preview, then use Clock style. Save applies the choice; Discard and Undo work with style edits too. Moving, resizing, choosing a starting layout or arranging modules keeps the style. A failed storage write preserves the saved dashboard.

Small modules and spacious layouts

The dial, time typography and date placement adapt to the actual module bounds. Landscape views fit without page scrolling at the tested sizes; narrow previews stack modules. These minimum/full-size captures use larger text and a late 12-hour time.
