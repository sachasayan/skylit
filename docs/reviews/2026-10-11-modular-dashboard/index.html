Place, resize, save

Open Settings → Dashboard. Drag a module by its name; drag its corner to resize. The layout snaps to a 12 × 12 grid and prevents overlaps. Select a module for exact Column, Row, Width and Height fields. Arrow keys move it; Shift + arrows resize it. Undo, Discard and Save make edits reversible.

The gallery supports tap-add or dragging its grip into empty space. Tap-add automatically makes room when needed and explains the rearrangement; Undo restores the previous layout. Direct drops require room. Dragging autoscrolls the Settings editor. Card bodies remain scrollable on touch.

Save writes the layout before applying it. A storage failure keeps the current dashboard. Removing a module retains its data. Balanced, Photos first and Agenda first remain starting layouts. Existing presets and the optional note excerpt migrate into the new editor.

Nine available modules

One of each module per dashboard. No new account connections, permissions or network providers. Module management arrows return to the existing Weather, Photos, Calendar or Household editors.
