Deliberate integration boundaries

The existing JavaScript adapters still coordinate routing, Settings arrangement and form writes, dashboard dragging, native callbacks and persistence. Forms use the existing write path. Momo, clock artwork, the slideshow scene engine and crop transforms retain their imperative renderers. This is a React rendering integration with retained adapters; it does not claim that every DOM operation has been removed.

Both preview and APK builds regenerate the local bundles from pinned dependencies. The phone bundle has a checked native size limit. No household data is included in these screenshots or the distributable APK.

The screenshots below are visual regression evidence, not another dashboard redesign. Small differences in Momo’s pose and scene motion are expected.
