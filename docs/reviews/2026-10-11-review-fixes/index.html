Verification

  • 68 JavaScript tests and 15 Python tests pass.
  • 61 isolated Android checks pass on the identity-verified USB D156 frame, using synthetic pictures and temporary in-memory preferences.
  • Four focused browser regressions, 31 full-app checks and 23 dashboard checks pass with zero runtime errors. The broader matrix covers nine viewports and both text profiles.
  • Normal signed APK: version 2.14.2, code 26, valid v1/v2/v3 signatures. Installed in place on Android 12 / WebView 95, at 1920×1080 physical / 1280×720 CSS.
  • Saved preferences survived the upgrade; the first-run guide stayed closed. Actual-frame draft/discard behavior and affected screens were checked privately.
  • Initial live checks reached the two-minute deadline while downloading attachments. Bounded 256 KiB IMAP fetch chunks reduced round trips; the subsequent read-only refresh completed successfully in 24–31 seconds. The frame remained responsive throughout.
  • Source, Git history and final APK privacy checks plus Gitleaks scans are recorded in the repository verification log.

Browser harnesses now wait for DOM readiness and explicit app initialization. Calendar worker cancellation can leave network-idle waits pending even when the app is ready; the final runs needed no startup retries.

All screenshots below come from the isolated synthetic preview. Actual-frame photos, calendars, account details and acceptance captures remain private. Stalled import/cancellation tests use isolated synthetic data; they do not establish long-term unattended mail reliability.
