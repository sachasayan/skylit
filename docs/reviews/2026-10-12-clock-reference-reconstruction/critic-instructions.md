# Critic process and instructions

Each style had a separate critic. The first phase supplied only its panel in the approved concept: no implementation, source, previous reports or verdicts. The critic inventoried observed construction, hierarchy, glyphs, material, silhouette and relationships; separated observation from inference and uncertainty; normalized proportions; and re-examined the target before locking.

A different critic then cross-validated each inventory: Landscape reviewed Flip; Flip reviewed Botanical; Botanical reviewed Landscape. The validation amended Flip's closed-counter 4, Landscape's sun prominence, and Botanical's wash/clearance descriptions. Direct comparison later caught another inventory error: Landscape's 4 was also closed. That amendment is retained in the review. Peer validation alone did not make the inventory infallible.

Implementation review instruction (style and evidence paths varied):

“Compare directly to the approved target and locked cross-validated inventory. Do not read source or prior implementation descriptions. Separate fidelity and responsive composition gates, feature statuses, no improvement credit. Report concrete remaining consequential discrepancies; explain permissible recompositions. Revalidate any disputed target interpretation with pixels, not rubric authority. Accept only if consequential reference/responsive gaps are resolved; document smaller remaining deviations.”

Each review inspected seven individual native crops, not just a reduced montage. Each feature had to be present, weakened, missing or contradicted. Different shapes could recompose text/art and omit constrained ornament; they still needed coherent hierarchy, complete intentional silhouettes, legibility and clear separation. Reference positions were not mandatory outside comparable proportions.

Theme presentation was a separate pass across all twelve medium light/dark variants per style. Flip additionally received actual paused browser animation samples, assessed separately from static fidelity. Neither shape nor theme acceptance establishes physical-device performance, measured accessibility or every size/theme combination.

The inventories, independent validation, initial rejections and final reviews are included. This is an adaptation of the user-requested dream-loop approach: validated target → implementation → separate critic → concrete correction → fresh rendered proof.
